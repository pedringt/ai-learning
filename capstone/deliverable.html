Handoff

Done
Reviewed the PM handoff for Meridian Support Operations — a Tier 1 support pilot where an AI agent classifies tickets, drafts responses, and routes risky or uncertain cases to a human. Raised 3 initial clarifying questions before moving to PLAN: whether formal pilot targets already existed, what the knowledge base's reliability actually was, and whether the human-boundary/escalation list in the handoff was complete. Set the core human boundary early: money and security categories never get an AI draft, and every AI draft — regardless of category — goes through mandatory human review before it reaches a customer.

Configure

In progress
Built the agent's flow logic: classify → (high-risk skips drafting, straight to human) or (retrieve → draft → confidence check) → human review → send → escalation check on replies. Escalation threshold (5+ exchanges) justified with real usage data rather than a guess. Retrieval built on semantic/embedding search instead of keyword matching, to sidestep the knowledge base's existing search problem. One standout catch: digging into why reps manually copy-pasted billing status into tickets found it was a simple display-config gap, not a new integration or approval need. Flow diagram is done; the actual no/low-code prototype build is optional, later practice.
