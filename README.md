# Practical AI Learning Portfolio

A static portfolio documenting applied AI learning, evaluation work, and small AI-assisted tools.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The site is configured for Vercel with `vercel.json`. Keep `index.html` and
`vercel.json` at the repository root.

The public activity-picker examples use fictionalized, privacy-safe demo data.
