# State manual release trust pass

Keep this short. Automation should already have covered mechanical regressions.

## 10-20 minute trust pass

- [ ] Add one realistic messy Evidence item.
- [ ] Confirm State's interpretation is sensible and not overconfident.
- [ ] Make one consequential Review decision.
- [ ] Confirm Current State changed only if it should have.
- [ ] Check the related Question behavior.
- [ ] Check History/provenance for the decision.
- [ ] Ask State what changed and what remains unresolved.
- [ ] Try one ambiguous or contradictory input.
- [ ] Switch projects once and confirm the old project's information does not linger.

While testing, ask:

- Would I trust this result as a project manager?
- Did anything become true that should not have?
- Did State hide uncertainty?
- Did State ask me to review something unnecessary?
- Did Ask sound more certain than the record supports?
- Was anything confusing, annoying, or hard to recover from?

Write findings using `docs/qa/REPORT_TEMPLATE.md`. Do not fix during the feedback pass.
