Choosing an AI Architecture

Decision guide: prompts, retrieval, fine-tuning, rules, tools, workflows, and agents.

Choose the simplest sufficient pattern

  • Deterministic rules: known logic, fixed permissions, calculations, validations. Predictable and testable; brittle for ambiguous interpretation.
  • Prompt-only model: summarization, drafting, classification with supplied context. Simple but limited by context and source freshness.
  • RAG: retrieve current or private evidence before generation. Needs source governance, indexing, and retrieval evaluation.
  • Tool calling: read live systems or perform actions through approved APIs. Requires scoped permissions, validation, audit, and failure handling.
  • Fixed workflow: predefined sequence combining deterministic steps and model calls. Easier to reason about than open-ended planning.
  • Agent: model decides which steps or tools to use toward a goal. Flexibility increases cost, variability, and testing burden.
  • Fine-tuning: adapt model behavior or style from examples; not a substitute for fresh knowledge, permissions, or authoritative state.

Two distinctions that prevent confusion

  • RAG vs fine-tuning: use retrieval when the problem is changing or proprietary facts; consider fine-tuning when repeated task behavior needs improvement and sufficient examples exist.
  • Workflow vs agent: use a fixed sequence when the path is predictable; consider an agent when paths vary meaningfully and its extra autonomy earns the complexity.
  • These approaches can be combined; they are not mutually exclusive alternatives.

Evaluation follows the layer

  • Retrieval: relevant source found, freshness, access filtering, ranking.
  • Model output: factual support, completeness, structured output, safety.
  • Tools/actions: correct tool, valid arguments, authorization, side-effect handling.
  • Whole workflow: task outcome, latency, cost, review effort, recovery.

Worked example

  • For a policy Q&A assistant: start with RAG against permission-filtered documents. For updating a customer's account, add a narrowly scoped tool plus approval. Use an agent only if the task requires variable multi-step investigation.
  • Do not put access policy or irreversible permission decisions solely in the prompt.

Questions to remember

  • Is the limitation missing facts, wrong behavior, missing actions, or a variable workflow?
  • Could rules or a fixed sequence do the job with less risk?
  • Where is authoritative state held, and what can the model change?
