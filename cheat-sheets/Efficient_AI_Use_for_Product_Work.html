PRODUCT WORK · AI OPERATING GUIDE

Use the lightest tool that can do the job well, then add power only when the work earns it.

1. Start with the job

2. Shrink context first

Ask what actually requires judgment. Use rules, queries,

schemas, or calculations for deterministic work.

Give the smallest useful context. Remove stale material before

reaching for a stronger model.

3. Match tool to task

4. Reuse, don’t rediscover

Fast model for routine work. Reasoning model for ambiguity.

Agent only for multi-step tool use.

Keep project briefs, decisions, eval cases, and good workflows

durable so AI does not relearn them each time.

5. Batch similar work

6. Structure the output

Cluster feedback, tickets, research, or eval cases together

when comparison is useful.

Prefer Decision / Evidence / Unknowns / Risks / Next step over

free-form conversation.

7. Bound agents

8. Escalate gradually

Give goal, permitted tools, escalation path, success condition,

and a stopping rule.

Known signal → likely source → adjacent evidence → broader

investigation. Do not start with every tool.

9. Verify with software

10. Measure real cost

AI interprets. Software checks. Humans decide when

consequences or ambiguity justify it.

Count latency, retries, review time, cleanup, tool calls, and bad

decisions — not just tokens.

BEFORE I USE AI

Does this require judgment?

What is the smallest useful context?

What is the cheapest capable model?

Can software verify any part?

What makes the AI stop?

How will I know the result is good?

Optimize for outcome per dollar, not tokens per dollar.
